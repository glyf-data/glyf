# Getting help with glyf

| You want to | Go to |
| --- | --- |
| Ask a question, or talk through how to do something | [GitHub Discussions](https://github.com/glyf-data/glyf/discussions), in Q&A |
| Report a bug | [Open an issue](https://github.com/glyf-data/glyf/issues/new/choose) |
| Propose a feature | [Open a feature request](https://github.com/glyf-data/glyf/issues/new/choose), or start in Discussions if it is still an idea |
| Report a security problem | **Privately**, through [GitHub's vulnerability reporting](https://github.com/glyf-data/glyf/security/advisories/new). See [SECURITY.md](./SECURITY.md). |
| Contribute | [CONTRIBUTING.md](./CONTRIBUTING.md) |

A discussion stays public, so the answer helps the next person with the same
question. When one finds a bug, it moves into an issue.

Before asking, run `glyf doctor` in your project and include its output. It
checks the manifest, the execution backend and the connection, which answers a
good share of questions by itself.

The documentation is at <https://glyfdata.com>.
