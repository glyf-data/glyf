# Existing dbt Project

Use this path when you already have a dbt project with models and a working profile.

## Install glyf

```bash
uv tool install glyf-core
glyf --version
```

The PyPI package is `glyf-core`; the command is `glyf`. See the
[installation guide](installation.md) for pipx/pip, upgrades, Windows, and
offline installs.

## Initialize the project

Run `init` from the dbt project root:

```bash
cd path/to/my_dbt_project
glyf init
```

The command asks for a starter chart name, dashboard name, dbt model ref, chart title, and chart type. It then creates:

```text
my_dbt_project/
  dbt_project.yml
  glyf.yml
  models/
  visualisations/
    monthly_revenue.ggsql
  dashboards/
    executive.yml
```

Use `--clean` when you want to rerun the scaffold and replace the starter chart/dashboard files:

```bash
glyf init --clean
```

## Update the starter files

Edit the generated `.ggsql` file so the SQL selects real fields from your dbt model:

```sql title="visualisations/monthly_revenue.ggsql"
SELECT month, revenue
FROM {{ ref('fct_revenue') }}

VISUALISE month AS x, revenue AS y
DRAW line
LABEL title => "Monthly Revenue"
```

Then confirm the generated dashboard YAML references the chart filename stem:

```yaml title="dashboards/executive.yml"
name: executive
title: Executive Dashboard
description: Starter dashboard generated by glyf init.
charts:
  - monthly_revenue
```

## Build dbt artifacts

`glyf` is artifact-driven, not dbt-runtime-driven. It does not run dbt for you.
Build or compile first so `target/manifest.json` exists.

```bash
dbt build
```

If you only need to regenerate the manifest:

```bash
dbt compile
```

## Check project health

```bash
glyf doctor
glyf validate
```

Use `--project-dir` when running from outside the dbt project:

```bash
glyf validate --project-dir path/to/my_dbt_project
```

## Generate dashboards

```bash
glyf build
glyf serve
```

If you want lower-level control, run the pipeline step by step instead:

```bash
glyf validate
glyf render
glyf dashboard
glyf export --clean
```
