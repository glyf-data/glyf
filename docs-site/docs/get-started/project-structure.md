# Project Structure

A dbt-charts project is a normal dbt project with chart and dashboard files added.

```text
my_dbt_project/
  dbt_project.yml
  dbt_charts.yml
  models/
  seeds/
  visualisations/
    monthly_revenue.ggsql
    revenue_by_region.ggsql
  dashboards/
    executive.yml
  target/
    manifest.json
    ggsql/
      compiled/
      charts/
      dashboards/
      site/
```

## Inputs

`dbt_project.yml` identifies the dbt project.

`target/manifest.json` is generated by dbt and used to resolve `ref()` and `source()` calls.

`visualisations/*.ggsql` contains SQL plus chart directives.

`dashboards/*.yml` groups rendered charts into static dashboard pages.

`dbt_charts.yml` is optional. It customizes paths, render formats, and dashboard settings.

## Outputs

`target/ggsql/compiled/` stores compiled SQL.

`target/ggsql/charts/` stores rendered chart artifacts.

`target/ggsql/dashboards/` stores generated dashboard pages.

`target/ggsql/site/` stores the publish-ready static site.

## Naming convention

The filename stem of a `.ggsql` file becomes the chart name used in dashboard YAML.

```text
visualisations/revenue_by_region.ggsql
```

```yaml
charts:
  - revenue_by_region
```
