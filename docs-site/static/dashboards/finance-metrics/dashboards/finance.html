Finance Metrics

Bookings, expenses, and margin by month and department.

Bookings Trend

Compiled SQL 
SELECT month, sum(bookings) as bookings
FROM "finance_metrics"."main"."fct_finance"
GROUP BY 1

Expenses by Department

Compiled SQL 
SELECT month, department, sum(expenses) as expenses
FROM "finance_metrics"."main"."fct_finance"
GROUP BY 1, 2

Gross Margin Share

Compiled SQL 
SELECT department, sum(gross_margin) as gross_margin
FROM "finance_metrics"."main"."fct_finance"
GROUP BY 1
