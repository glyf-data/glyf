Product Analytics

Product usage and activation metrics by plan.

Active Users

Compiled SQL 
SELECT week, sum(active_users) as active_users
FROM "product_analytics"."main"."fct_product_usage"
GROUP BY 1

Activation by Plan

Compiled SQL 
SELECT week, plan, sum(activated_users) as activated_users
FROM "product_analytics"."main"."fct_product_usage"
GROUP BY 1, 2

Sessions vs Active Users

Compiled SQL 
SELECT active_users, sessions, plan
FROM "product_analytics"."main"."fct_product_usage"
