Activation

Compare activated users and activation rates by plan.

Activation by Plan

Compiled SQL 
SELECT week, plan, sum(activated_users) as activated_users
FROM "product_analytics"."main"."fct_product_usage"
GROUP BY 1, 2

Activation Rate by Plan

Compiled SQL 
SELECT
  week,
  plan,
  round(sum(activated_users) * 100.0 / nullif(sum(active_users), 0), 1) as activation_rate
FROM "product_analytics"."main"."fct_product_usage"
GROUP BY 1, 2

Engagement Mix

Sessions per active user and total session share by plan.

Sessions per Active User

Compiled SQL 
SELECT
  week,
  round(sum(sessions) * 1.0 / nullif(sum(active_users), 0), 2) as sessions_per_user
FROM "product_analytics"."main"."fct_product_usage"
GROUP BY 1
